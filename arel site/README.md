Enoncé « Le guide HTML/CSS pour Débutants »

Instructions générales :
Pour l’école en ligne « Digital Student », votre entreprise doit créer un site one page en
HTML5 et CSS3 qui présente un guide d’introduction au HTML/CSS destiné à des débutants.
Le site doit être structuré de manière simple, mais doit respecter les bonnes pratiques en
matière de sémantique HTML, d’accessibilité et de responsive design.
Structure du site :

Votre site devra être divisé en 5 sections principales :
1. Introduction
Accueillez le visiteur en lui présentant le sujet du guide et ce qu'il va pouvoir
apprendre grâce au site.
2. Pourquoi apprendre HTML/CSS ?
Exposez différentes raisons qui expliquent l'intérêt d'apprendre HTML et CSS pour
construire des sites web modernes.
3. Les balises de base
Listez et expliquez les balises HTML de base :
<h1>, <p>, <a>, <img>, <ul>, <li>, etc.
Incluez un ou plusieurs exemples d’utilisation pour chaque balise.
4. Tips & bonnes pratiques
Donnez quelques conseils pratiques pour un code HTML/CSS bien structuré, lisible et
optimisé. (Inspirez-vous de votre propre expérience ;) )
5. Contact
Créez un formulaire de contact avec les champs et éléments suivants :
• Avec une petite phrase d’accroche « Vous avez une question ? »
• Prénom
• Email
• Message
• Checkbox newsletter
• Un bouton « Envoyer » et un bouton « Effacer »
Le formulaire n’a évidemment pas besoin d’être fonctionnel, mais doit être bien
structuré et lisible.

Critères à respecter :
• Structure HTML : Utilisez des balises sémantiques appropriées pour chaque
section.
• Design : Le site doit respecter la charte graphique imposée (couleurs, polices
et mise en page). Vous utiliserez Flexbox et Grid pour organiser le contenu de
manière clair. Vous devrez également appliquer des media queries pour que
le site soit responsive avec une version desktop et une version mobile
(réfléchissez bien à vos breakpoints).
• Accessibilité : Assurez-vous que votre site soit accessible, qu’il ait une
navigation au clavier fluide.
• IA : L’utilisation de l’ia est éliminatoire, vous devez être en capacité de faire
vos propres recherches.
• Formulaire : Le formulaire de contact doit être fonctionnel en termes de
structure HTML.
• Code propre : Le site doit être bien organisé, optimisé (pensez aux pseudoclasses et aux variables) et avec un code propre (indentation, commentaires si
nécessaire et validation via le site du w3c).

Échappement des caractères HTML :
Lorsque vous souhaitez afficher des balises HTML comme du texte et donc éviter qu'elles
soient interprétées par le navigateur, vous devez échanger les caractères spéciaux
comme ceci :
• Utiliser les balises blocs <pre> et <code>
• Remplacer < par &lt;
• Remplacer > par &gt;
