# projetFilRougeArel

L’AREL : Association Régionale d’Études des langues. 
L'association à pour but de promouvoir pour les adultes de tous âges – du débutant au pratiquant confirmé - l’étude des langues vivantes grâce à des professeurs diplômés (l’anglais, l’espagnol, l’italien, le portugais, l’allemand). 
Pour augmenter leur visibilité, l'AREL souhaite avoir un site internet qui rassemble et promeut les informations de l'association.
Elle veut pouvoir faciliter les inscriptions en rendant le lien du formulaire d'inscription disponible sur le site.
Elle aimerait aussi pouvoir tenir informer les adhérents tout comme les visiteurs de certaines actualités tout en ayant la possibilité de les modifier par eux même une fois le site terminé.
Elle aimerait que la création de ce site permettent de créer du lien avec d'autres associations locales.
Et pour finir, le site permettrait de mettre en avant le recrutement pour l'association, que ce soit pour les enseignants ou pour les membres du bureau.
